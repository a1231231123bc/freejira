# Roadmap

These are proposed directions, not delivery commitments. Open an issue to discuss priorities.

- Bring video task intake and external connection management to the self-hosted edition.
- Document and test migrations between editions.
- Improve keyboard and assistive-technology coverage; add English UI localization.
- Define per-project access controls and a complete backup/restore flow for Sites video data.
- Expand end-to-end coverage for concurrent collaboration and responsive layouts.

Automatic QA is maintained separately in Freejira QA. Features are not described as available until implemented and tested.
