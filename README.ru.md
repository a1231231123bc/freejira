# Freejira

Пространство для небольшой команды, которая параллельно ведёт несколько проектов. Задачи, канбан, сроки, участники и MCP работают с общей базой.

- **Самостоятельное размещение:** Node.js 24+, React, Express и SQLite. Запускается на своём компьютере или сервере. [Установка, общий доступ, MCP и резервные копии](docs/self-hosting.ru.md).
- **Версия Sites:** вход ChatGPT, D1/R2, внешний MCP, задачи из видео с подтверждением человеком. [Инструкция](editions/sites/README.md). Требует доступа к платформе Sites.
- **Автоматический QA:** [отдельный репозиторий](https://github.com/a1231231123bc/freejira-qa), GitHub PR, локальные проверки и Ollama. По умолчанию оставляет комментарий, решение о закрытии задачи остаётся человеку.

Версии используют разные базы и не синхронизируются. Разбор видео есть только в Sites. Интерфейс — на русском, общие документы проекта — на английском.

## Запуск

```sh
git clone https://github.com/a1231231123bc/freejira.git
cd freejira
npm ci
npm run build
npm start
```

Откройте http://localhost:4173 и создайте владельца. Данные сохраняются в `data/freejira.sqlite`. Для разработки — `npm run dev`. Для Docker — `docker compose up -d --build`.

Проект на ранней стадии. Все активные участники видят общие проекты; отдельных прав на проект нет. Перед публикацией сервера создайте владельца, настройте HTTPS и резервное копирование.
