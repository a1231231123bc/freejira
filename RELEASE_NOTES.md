# v0.1.0 — first public preview

Self-hosted project management with SQLite, team accounts, kanban and MCP. Also includes the separate Sites edition with D1/R2, video task intake and external MCP pairing.

The quick start runs the self-hosted edition. Video processing requires the Sites edition and separate worker setup.

Includes MIT license, English/Russian documentation, contribution and security guidance, example configuration and CI. This is an early release, without a stability or support SLA.
