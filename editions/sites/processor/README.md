# Обработчик видео на Mac

Сервис сам забирает задания с Freejira по исходящему HTTPS. Публичный порт или постоянно включённый второй браузер не нужны. Tailscale/SSH используются только для установки и обслуживания.

Рекомендуемый каталог установки: `~/.local/share/freejira-video`. Сервис `com.freejira.video-worker` стартует при входе этого пользователя в macOS и перезапускается после сбоя. `caffeinate -i` предотвращает автоматический сон по бездействию; закрытие крышки/ручной сон всё равно могут остановить работу. Держите Mac включённым, с интернетом и питанием. При выключении задания остаются в D1, после возвращения Mac очередь продолжается.

## Зависимости

Проверенная конфигурация: Apple Silicon, Python 3.12, `mlx-whisper==0.4.3`, `numpy`, `Pillow`, `jsonschema`, `requests`; FFmpeg/ffprobe 9.0.2, Node 24, официальный `@openai/codex` 0.164.0. FFmpeg и Node установлены через conda-forge в изолированное окружение micromamba, Python — через uv. Whisper использует `mlx-community/whisper-large-v3-turbo`; модель скачивается при установке и остаётся в локальном кеше Hugging Face.

Codex должен быть установлен из официального npm-пакета и авторизован через `codex login`. Используется подписка ChatGPT и её лимиты, отдельного платного API-ключа нет. Проверка: `codex login status`. Не переносите `auth.json` с других компьютеров. При отключённом входе по коду устройства используйте обычный браузерный вход; для удалённого SSH разрешён локальный callback через порт 1455.

`config.json` (не хранить в Git, права 0600):

```json
{
  "site_url": "https://YOUR-SITE.chatgpt.site",
  "worker_token": "тот же секрет, что VIDEO_WORKER_TOKEN в Sites",
  "site_access_token": "секрет служебного доступа к закрытому Sites",
  "codex": "/ABSOLUTE/runtime/codex/node_modules/.bin/codex",
  "node": "/ABSOLUTE/runtime/media/bin/node",
  "ffmpeg": "/ABSOLUTE/runtime/media/bin/ffmpeg",
  "ffprobe": "/ABSOLUTE/runtime/media/bin/ffprobe"
}
```

Секрет `VIDEO_WORKER_TOKEN` задаётся в окружении Sites, после изменения нужна публикация. `site_access_token` нужен для закрытого сайта и передаётся в `OAI-Sites-Authorization`; токен обработчика дополнительно защищает его API. Эти секреты не попадают в клиентский JS. Обычные API и MCP по-прежнему требуют активного пользователя команды.

Копируйте `worker.py`, `video_core.py`, `result.schema.json` и `install-service.py` в каталог обработчика. При готовых runtime/venv/config запустите `venv/bin/python install-service.py`.

Проверка: `launchctl print gui/$(id -u)/com.freejira.video-worker` и `tail -30 logs/worker.log`. Остановка: `launchctl bootout gui/$(id -u)/com.freejira.video-worker`. Возобновление: `venv/bin/python install-service.py`.

## Обработка и данные

D1 хранит очередь, транскрипт, JSON, связи задач, обсуждение и метрики. R2 хранит исходник, кадры и при необходимости MP4-копию H.264/AAC для браузера. Mac хранит модель Whisper и конфигурацию; рабочие видео/аудио/кадры удаляются после завершения или обработанной ошибки. На OpenAI отправляются выбранные кадры и расшифровка через Codex; распознавание речи выполняется на Mac.

Задания арендуются на 120 секунд с продлением каждые 20 секунд. После прерывания обработка возобновляется, максимум три захвата до понятной ошибки. Работа последовательная, поэтому ожидающая очередь увеличивает время до готовности. Выход за лимиты подписки показывается как ошибка, доступен повтор. Модель и задержки Codex могут влиять на время. Токены и длительности этапов доступны в разборе; стоимость в деньгах не рассчитывается, поскольку используется подписка.

Загрузка кадров и частей видео повторяется до трёх раз при временных сетевых ошибках. Для отправки части файла предусмотрен тайм-аут 60 секунд; соединения переиспользуются. Совместимые H.264/AAC файлы MP4/MOV проигрываются из оригинала, остальные преобразуются в MP4.

Одно выполнение передаёт кадры и речь в хронологическом порядке, требует JSON Schema и повторяет невалидный ответ один раз. Инструменты shell/web отключены; модель получает только входные материалы и не создаёт задачи. Создание выполняется сервером только после явного подтверждения в UI. Уникальный отпечаток задачи и SQL-транзакция защищают от двойного клика; повторный анализ получает уже созданные предложения, сервер также сопоставляет исходное название и близкие названия с тем же доказательством. Существенно переименованную моделью задачу всё равно следует проверить человеку.

## Проверки

- `venv/bin/python -m unittest test_video_core test_worker -v`: резкость, окна, dHash, равномерное прореживание, хронология, повторная передача после сетевого сбоя, защита от повторного захвата задания.
- `node --test tests/video.test.mjs` в репозитории: JSON, кадры, цитаты, таймкоды, пользователи, даты.
- `node tests/video-api.mjs` против локального Worker: загрузка, права, подтверждение, создание, гонки, дубли, чек-лист, R2 Range.
- Реальный тест: синтетическая запись экрана 2:30 с русской речью — 85,51 с от скачивания до готового результата; 2 задачи, цитаты и кадры. Запись без аудио — 23,18 с, все предложения low и не выбраны. Это измерение конкретных тестов, не SLA для любого видео.
