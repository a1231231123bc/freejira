# Freejira on Sites

Общее рабочее пространство для нескольких параллельных проектов, небольшой команды и AI.

## Использование

Откройте сайт, войдите через ChatGPT и создайте пространство. Первый участник становится владельцем. Демонстрационные проекты добавляются только по желанию при первом запуске.

- Обзор проектов, прогресс и просроченные задачи.
- Канбан с перетаскиванием, таблица, общие и личные задачи.
- Ответственные, сроки, приоритеты, метки, комментарии и история действий.
- Избранное, архив, глобальный поиск `⌘K` / `Ctrl+K`, создание задачи клавишей `C`.
- JSON-экспорт без секретов и служебных идентификаторов ChatGPT.
- MCP с 12 инструментами и ресурсом `freejira://workspace/summary`.

## Доступ команды

Сайт изначально закрыт для всех, кроме владельца. Чтобы пригласить коллегу:

1. Разрешите ему доступ через «Поделиться» в Sites. Доступные аудитории и внешние посетители зависят от вашего аккаунта Sites.
2. На странице «Команда» создайте приглашение для email его аккаунта ChatGPT.
3. Передайте ссылку коллеге. Она одноразовая, действует 7 дней и привязана к этому email.

Внешние письма приложение не отправляет. Все активные участники могут читать и редактировать общие проекты. Отдельных закрытых проектов пока нет. Отключение участника закрывает доступ к приложению и MCP без удаления его задач и комментариев.

Вход выполняется платформой Sites; приложение не хранит пароли и не реализует отдельную систему сессий. Пользователи привязаны к стабильному идентификатору аккаунта внутри сайта. Email используется только для отображения и проверки приглашений.

## MCP

Sites автоматически создаёт личный плагин при публикации. Подключите Freejira через «Плагины → Личные → Созданные вами» в ChatGPT/Codex. Если инструменты ещё не видны после подключения, начните новый чат.

Инструменты: `list_projects`, `get_project`, `create_project`, `update_project`, `list_tasks`, `get_task`, `create_task`, `update_task`, `add_comment`, `list_members`, `workspace_summary`.

Endpoint `/mcp` поддерживает stateless JSON-RPC `server/discover` (2026-07-28), стандартный `initialize` для 2025-03-26 / 2025-11-25, `tools/list`, `tools/call`, `resources/list` и `resources/read`. Действия выполняются от имени пользователя, предоставленного Sites. Каталог инструментов не раскрывает данные команды; вызовы требуют активного членства. Клиенту следует прочитать актуальный `revision` перед изменением задачи или проекта.

## Архитектура

React / TypeScript / Vinext. Серверные API в `app/api/[...path]/route.ts`, MCP в `app/mcp/route.ts`. `lib/freejira/` содержит валидацию, авторизацию и работу с общей D1-базой. D1 миграции генерируются из `db/schema.ts` и применяются Sites при публикации. Данные браузера ограничены настройками вида; задачи хранятся на сервере. Другие браузеры обновляют данные каждые 10 секунд и при возвращении на вкладку. При открытии задача дополнительно перечитывается с сервера.

Мутации используют D1 `batch()` для атомарности; обновления защищены проверкой версии. Номера задач выделяются в одном SQL-запросе и остаются уникальными при параллельном создании.

## Разработка и проверка

Нужен Node.js 24+ одной архитектуры для установки и запуска. Используйте Sites helpers из установленного плагина для установки, сборки и публикации. Для локальной сборки скопируйте `.openai/hosting.example.json` в `.openai/hosting.json`. При публикации зарегистрируйте **новый** Site через плагин Sites и сохраните выданный `project_id` в локальном manifest. Файл с идентификатором не хранится в Git.

`npm run dev -- --port 5177` — локальная разработка. В portable preview `/signin-with-chatgpt?return_to=/` создаёт тестовую сессию `seedy@sites.test`. Это поведение отсутствует в опубликованном Worker.

После сборки локальные миграции применяются командой из инструкции Sites, затем `npm start -- --port 5178` запускает настоящий Worker в локальной среде. `node tests/cloud-smoke.mjs` проверяет этот preview: реальный D1, конкурирующие записи, приглашения, права, комментарии, экспорт и MCP. Тест отказывается работать с нелокальными адресами, использует имитированные идентификаторы и не касается опубликованной базы.

В браузере проверены создание и редактирование задач, приглашения, совместная работа, поиск, канбан и мобильная ширина. Локальный Node/SQLite-вариант и browser/API tests находятся в корне репозитория.

## Задачи из видео

1. В проекте или общем списке нажмите **«Задачи из видео»**. Выберите проект, видео MP4/MOV/WebM до 500 МБ и 15 минут, при необходимости добавьте контекст.
2. Дождитесь окончания загрузки. После этого страницу можно закрыть: разбор выполняется на Mac, уведомление появится в Freejira. Состояние Mac показано в разделе «Задачи из видео».
3. Проверьте предложенные задачи: название, тип, описание, критерии, исполнителя, принимающего, срок и прикрепляемые кадры. Таймкоды перематывают плеер; доступны полная расшифровка и описание экранов.
4. Отметьте нужные карточки и нажмите **«Создать задачи»**. Они попадут в **«К выполнению»** с чек-листом, кадрами, цитатой и ссылкой на разбор. Сомнительные предложения и задачи из видео без звука по умолчанию не выбраны.
5. Вопросы можно добавить в обсуждение видео. Повторный разбор с другим контекстом сохраняет связь с созданными задачами. Проверяйте смысл предложений перед подтверждением.

В этой редакции данные команды сохраняются в D1-базе вашего Site, видео и кадры — в его R2. Виртуальная машина для хранения не нужна. Второй Mac выполняет обработку; голос распознаётся локальным Whisper, кадры и расшифровка анализируются Codex с использованием лимитов подписки ChatGPT. Работа требует включённого Mac и интернета. API-ключ платного AI не нужен. Существующий JSON-экспорт пространства содержит обычные задачи; он не является полной резервной копией видеоматериалов R2 и разборов.

Инструкция по обслуживанию: [processor/README.md](processor/README.md). Настройки отбора кадров доступны владельцу внизу раздела: окно 3 секунды, dHash 6 бит, не более 60 кадров. MCP `get_task` возвращает также источник видео, чек-лист и список кадров.

## Claude Code

Внешнее подключение к той же облачной базе: [установка и рабочий сценарий](mcp/README.md). Команда `/freejira-task DEMO-12 review` читает задачу и материалы, переводит в работу, помогает реализовать и проверить код, добавляет результат и меняет колонку. Подключение подтверждается в интерфейсе, доступ можно отозвать. Ключ даёт чтение, обновление задач и комментарии; удаление задач и изменение проектов недоступны.

## Публичный шаблон

Исходники не содержат чужого Site ID, базы или служебных токенов. Hosted auth и dispatch требуют платформу Sites; перенос на произвольный Cloudflare Worker требует отдельной реализации авторизации. Для независимого сервера используйте корень репозитория. Локальный mock-вход предназначен только для разработки.
